Registering another prefix

The engine resolves any URI its filesystem layer understands — a local path or an S3-compatible bucket. It opens one Parquet footer to infer the schema, parses Hive-style key=value directory names into partition columns, and records the file inventory. The data itself is never read or moved. 

python manage.py register_dataset trips ./data/trips
python manage.py register_dataset events s3://my-bucket/events
